# Artigo

Rascunhos, template e figuras finais do artigo (inglês, coluna única, até 20 páginas incluindo referências).

- `template-sbc/`: template LaTeX da SBC, copiado do pacote "Template para Artigo SBC" do Moodle (só os fontes; os arquivos de compilação ficam fora do Git). O pacote também traz versões `.doc` e `.odt`. Confirmar no Moodle qual formato é o exigido (Etapa 11).
- Estrutura e orçamento de páginas: `docs/PLANO.md`, seção 9.
- Tabelas e figuras vêm de `results/tables/` e `results/figures/`, geradas por `make report`. Nada é copiado à mão.
- Declaração de uso de IA e material suplementar: montados a partir de `docs/IA_LOG.md`.
